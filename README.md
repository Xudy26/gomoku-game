# 五子棋游戏 (Gomoku Game)

一个精美的五子棋游戏，使用 Python 和 Pygame 开发，具有出色的视觉效果和完整的游戏功能。

## 功能特性

### 🎮 游戏模式
- **双人对战**: 本地双人对战模式
- **人机对战**: 与 AI 对战，支持三个难度级别（简单、中等、困难）

### 🎨 视觉效果
- 精美的粒子系统（背景粒子、涟漪效果、庆祝动画）
- 3D 效果棋子渲染（渐变、高光、阴影）
- 流畅的落子动画和涟漪效果
- 华丽的胜利庆祝动画
- 三种主题风格（经典木纹、现代简约、暗黑风格）

### 🎵 音效系统
- 落子音效
- 胜利/失败音效
- 背景音乐
- 音量控制功能

### ⚙️ 设置系统
- 音量控制（主音量、音乐、音效）
- 棋盘大小选择（13x13、15x15、19x19）
- 主题切换
- 数据持久化存储

### 📊 游戏统计
- 详细的游戏统计（胜率、连胜、各模式统计）
- 历史战绩记录

## 安装说明

### 系统要求
- Python 3.6 或更高版本
- Pygame 库

### 安装步骤

1. 克隆仓库
```bash
git clone https://github.com/yourusername/gomoku-game.git
cd gomoku-game
```

2. 安装依赖
```bash
pip install pygame
```

3. 运行游戏
```bash
python gomoku.py
```

## 使用方法

### 主菜单
- **双人对战**: 开始本地双人对战
- **人机对战**: 选择难度后与 AI 对战
- **游戏设置**: 调整音量、棋盘大小、主题
- **游戏统计**: 查看游戏统计数据
- **退出游戏**: 退出程序

### 游戏操作
- **鼠标点击**: 在棋盘上落子
- **悔棋**: 撤销上一步棋
- **重开**: 重新开始游戏
- **菜单**: 返回主菜单
- **快捷键**:
  - `R`: 重新开始
  - `U`: 悔棋
  - `ESC`: 返回菜单/退出游戏

### AI 难度说明
- **简单**: 搜索深度 2，有 30% 随机性
- **中等**: 搜索深度 3，平衡策略
- **困难**: 搜索深度 4，最优策略

## 技术特点

### 核心架构
- 游戏状态管理系统
- 场景管理器（主菜单、游戏场景、设置场景、统计场景）
- 资源管理器（字体、音效、图片）
- 数据持久化存储（JSON 格式）

### AI 算法
- Minimax 算法
- Alpha-Beta 剪枝优化
- 棋型评估系统（连五、活四、冲四、活三等）

### 视觉系统
- 粒子系统（背景、涟漪、庆祝、闪烁）
- 3D 棋子渲染
- 动画效果系统
